# StreamBridge

[Open the TV receiver](https://species84720.github.io/StreamBridge/). Bookmark this address on your TV.

1. Run StreamBridge on the phone or Windows computer, and leave TV hosting active.
2. On the TV enter the sender IP. Choose Android (39847) or Windows (57984), or enter IP:port directly.
3. Enter the sender's six-digit pairing code. Saved senders reconnect in the local receiver.

The public HTTPS page opens the local sender receiver because TV browsers can block HTTP network discovery from an HTTPS page. This is a deliberate local connection: the phone/computer still supplies video, and must remain on the same home network. The browser may request permission to open the local address. GitHub Pages cannot run a raw UDP LAN scanner or relay authenticated video. Local HTTP and packaged receivers can scan the two StreamBridge sender ports; this is not a general port scanner.

Use the remote arrow keys, OK, Back and media keys for playback and settings. Codec support depends on the TV. Existing /app/ bookmarks redirect here.

For the Samsung setup confirmed to run Android APKs, use the separate StreamBridge TV Android receiver. It has a native video player, UDP/HTTP sender discovery, manual IP entry, saved pairing and remote controls. Use the phone sender APK on the phone, and the TV receiver APK on the TV. Physical TV playback still needs validation.

VIDAA community installation and the unfinished cloud QR experiment have been retired. No cloud pairing server is required by this receiver.
