# StreamBridge community receiver

This is the hosted player used by the StreamBridge community VIDAA installer. Open ../index.html for the installer. The installed home-screen tile loads this directory over local HTTP; it is not an offline TV firmware application. Community installation remains dependent on the TV firmware and installer API. Keep the hosting computer awake. No VIDAA partner account is required to attempt the community method.

HLS.js and its license are included.
