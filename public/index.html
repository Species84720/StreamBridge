StreamBridge on VIDAA

Community installer · Your phone and computer, on your TV

Install a StreamBridge tile on the Hisense home screen. The receiver remains hosted on your home server.

Local HTTP is recommended for phone/PC video playback. A public HTTPS receiver may block local HTTP streams.

First installation

  1. Temporarily set only this TV's DNS to 192.168.68.73.
  2. Start the temporary installer service on the server, then open https://vidaahub.com/ on the TV. The local installer uses a self-signed certificate.
  3. Choose Install StreamBridge. Restore the TV's original DNS afterwards, then restart the TV if the tile does not appear.

No firmware changes are made. Installation depends on the VIDAA firmware exposing its community install API. GitHub Pages can host this page, but cannot grant the vidaahub.com install API.
